## 1.0.19

- Added a draggable always-on-top NHI desktop mascot for configured MAP users, including rounded task bubbles and a complete incoming/outgoing task board.
- Added per-task urgency and task creator display; local agents now choose priority from task context.
- Added after-meeting NHI reminders using only the recipient's local Google Calendar, with both native and mascot notifications.
- Added durable recipient-owned agent-chat bindings: a task now opens the recipient's own saved Codex conversation instead of the originator's chat.
- Codex in VS Code now types and submits the full NHI briefing through macOS Accessibility instead of only copying it to the clipboard.
- Added local NHI debug improvements and remembered mascot position.
