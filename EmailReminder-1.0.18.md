## 1.0.18

- Added a built-in local NHI MCP server and native helper for Claude Desktop. The helper keeps MAP and Google credentials in Email Reminder and exposes a documented delegation skill and typed NHI tools.
- Added one-click Claude Desktop MCP connection setup, with no per-user skill script or manually copied bridge token.
- Added exact schema guidance for creating NHI delegations, including access groups, resolved assignees, expected results, and artifacts.
- Added built-in Codex Desktop, Claude Desktop, VS Code, and CLI agent profiles, plus a default NHI access-group setting.
- Added an optional floating NHI debug console for local Bridge, synchronization, and agent-launch diagnostics.
- Claude Desktop handoffs now open a new Code chat, type the task briefing directly, and submit it without using the clipboard when Accessibility permission is granted.
